Live demo

These are the reports farol produced in CI for a real pull request on the FastAPI full-stack template (a FastAPI backend and a React frontend with TanStack Router). The pull request, “Items: status, filter by status and an Insights page”, was written for this demo: a realistic feature with the problems a reviewer should catch.

Everything is interactive: mark files as reviewed, mark pages as behind a feature flag, open the inline diffs and copy the review record from the Result tab. Your marks stay in your browser.

How these were made
  • The pull request's workflow ran the project's tests with coverage, ruff and pip-audit, then farol on each side: no code of the pull request is run by farol itself.
  • The same reports are linked from the pull request comments, one per side, on every push.
  • Workflow and setup: examples/README.md.
